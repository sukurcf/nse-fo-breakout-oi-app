Import normalized candles

Five-minute source bars for deterministic replay.

exchange,symbol,provider_instrument_id,interval_start,interval_end,open,high,low,close,status,provider_time,source
volume is optional. Timestamps must include timezone offsets; rows must be chronological per symbol.

Only complete/corrected bars can generate events. Missing opening bars, stale bars, gaps, mapping mismatches, and invalid OHLC suppress affected calculations.

Contract context only; scoring is uncalibrated.

No OI score, percentage change, expiry selection, nearby-strike aggregate, or directional claim is calculated.
